# 修复计划文档模板（活文档模式）

阶段三生成修复计划时使用此模板。写入路径为项目根目录下的 `.bugfix-workflow/bugfix-plan-YYYY-MM-DD.md`，写入前确保 `.bugfix-workflow/` 目录存在。

## 活文档机制

本模板采用活文档（Living Document）模式：Agent 在修复过程中实时更新文档中的状态标记，中断后可从此文档恢复进度。

### 状态标记约定

| 标记 | 含义 | 何时标记 |
|------|------|---------|
| `⬜` | 待开始 | 计划生成时默认 |
| `🔄` | 进行中 | 开始执行该 Bug/步骤时 |
| `✅` | 已完成 | Bug 修复完成或步骤全部执行完毕 |
| `⏭` | 已跳过 | 不需要处理时 |

### Agent 更新规则

1. **开始执行**：将对应项标记从 `⬜` 换为 `🔄`
2. **执行完毕**：将对应项标记从 `🔄` 换为 `✅`
3. **跳过**：将对应项标记为 `⏭` 并填写备注
4. **进度总览**：每完成一个阶段，同步更新进度总览表的状态
5. **恢复执行**：读取进度总览表，从第一个 `⬜` 或 `🔄` 的阶段继续
