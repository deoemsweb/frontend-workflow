## 修复 figma-design-constraint.md 的 Token 重复定义问题
- 现象：还原 Figma 时，skill 把整段 `:root` Token 复制到每个组件的 `<style>` 中。
- 根因：2.4 只禁止"硬编码"，没禁止"重定义"；且 `<style scoped>` 内的 `:root` 会被 Vue 编译器改写为 `:root[data-v-xxx]`，因 `<html>` 无该属性而**失效**。
- 修复（已落到文件）：
  - 新增 §2.5「Token 定义位置与单一来源」：全局仅 `src/styles/tokens.css` 定义一次、入口 import 一次；组件只消费；明确 scoped 下 `:root` 失效陷阱。
  - §十四 第二步第 3 点强化：Token 表统一写入全局 tokens.css，组件只引用。
  - §十 10.9 代码质量新增检查项：Token 未在各组件重复声明。
  - §十五 新增错误示例 8（重复定义 Token 的反例）。
  - 同步更新 `技能使用提示词模板/01-Figma还原.md` 与 `frontend-workflow-usage.md` 5.1，触发即约束。
