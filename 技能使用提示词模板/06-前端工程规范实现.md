# 提示词模板 05：前端工程规范实现（业务逻辑绑定）

> 规则依据：`references/frontend-engineering-standards.md`（API 集成、状态管理、第四章安全硬约束、性能、注释）。
> 适用：在已生成的静态页面 / PRD 基础上实现业务逻辑、集成接口、状态管理。

---

## 模板 A：完整版

```text
请使用 frontend-workflow skill，按 frontend-engineering-standards.md 实现下面业务逻辑（基于已生成的静态页面 / PRD）。

【输入】
- 静态页面 / 组件：{{page_or_component_path}}
- PRD tasks.md（可选）：{{tasks_path}}
- 技术栈：{{tech_stack}}                  # 如 Vue2/JS/ElementUI + Vuex
- 输出目录：{{output_dir}}

【执行要求】
1. 设计桥梁（SKILL ⑧）：先产出组件树 / 状态 / 数据流草案给我确认，再写代码。
2. 按 frontend-engineering-standards.md 实现：
   - API 三态（loading / error / empty）+ 请求取消 / 防竞态（组件销毁时 abort）；
   - 状态管理按现有 module 模式（本项目 Vuex 3，src/store/）；
   - 安全硬约束（第四章，无论需求是否体现都必须遵守）：禁用 v-html（本项目用 v-rich-text 指令）、用户输入转义、URL 协议校验（禁 javascript:/data:）、禁止硬编码 API Key / Token / 密码、禁止 console.log 敏感信息；
   - 性能：图片 loading="lazy" + 明确尺寸、路由 / 组件懒加载、搜索防抖 / 滚动节流、长列表(>100)考虑虚拟滚动；
   - 注释：工具函数 / Hook / Store action 写 JSDoc，复杂逻辑必注释，TODO/FIXME 带责任人 + 日期。
3. 本项目适配：Options API；API 走 src/utils/http/http.js 封装，新接口按业务模块归类且写完善出入参注释；复用已注册自定义指令（v-permission / v-role / v-copy / v-click-outside / v-number / v-rich-text 等），不重复实现。
4. 完成后「检查 Agent」跑工程硬约束 + 非功能质量，单环节最多回流 3 次；到达人工 Gate（⑪）暂停验收。

【硬约束】安全规则全程生效；信息不足停止询问，严禁猜测业务规则 / 接口契约。
```

## 模板 B：精简版（一行触发）

```text
用 frontend-workflow skill 按 frontend-engineering-standards.md 给 {{page_or_component_path}} 实现业务逻辑，写到 {{output_dir}}。先出组件树/状态草案确认；遵守第四章安全硬约束（用 v-rich-text 不用 v-html）、API 三态+防竞态、复用已有自定义指令；完成后过检查并等我验收。
```

## 占位符说明

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{{page_or_component_path}}` | 待绑定业务的页面 / 组件路径 | `src/views/order/list.vue` |
| `{{tasks_path}}` | 可选 PRD 任务清单 | `openspec/changes/add-export/tasks.md` |
| `{{tech_stack}}` | 技术栈 | `Vue2.6 + JS + ElementUI2 + Vuex3` |
| `{{output_dir}}` | 输出目录 | `src/views/order/` |
